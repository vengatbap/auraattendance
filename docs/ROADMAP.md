# Roadmap - V2 Parking Lot

This document lists the modules and features postponed to the V2 roadmap, keeping the V1 release focused and minimal.

## Postponed V2 Features

1. **QR Attendance:** Quick response check-ins for visitor management or secondary card logs.
2. **Leave Management:** Custom leave requests, approvals, balance logs, and team planners.
3. **Shift Scheduling:** Multi-shift planning, rotations, roster rules, and calendar syncs.
4. **Holiday Calendars:** Public holiday directories and custom tenant-level holiday overrides.
5. **Overtime Calculations:** Advanced overtime trackers, custom rates, and thresholds validation.
6. **Mobile Application:** Native iOS and Android employee punch applications.
7. **WhatsApp Notifications:** Automatic check-in warnings and monthly attendance digests sent directly via WhatsApp.
8. **Payroll Module:** Automated salary settings, hourly calculators, deductions ledgers, and printable payslip receipts.
9. **Biometric Device Integration:** Integrations with physical ZKTeco, Hikvision, or custom fingerprint/face card hardware terminals.
10. **Custom API Integrations:** Webhooks and public REST endpoints for external HR platforms.
